# 차여기 — 주차 위치 기록 모바일 웹 MVP (v1.0)

> **제품 전체 PRD:** [차여기 서비스 요구사항 정의서 v1.0](docs/CHAYEOGI_PRD_v1.0_2026-11-02.md) — 사용자 행동, UX·기능 정책, 데이터 구조, QA, 로드맵, 사업화.

## 1. 무엇이 구현되어 있나요?

- **사진 촬영 즉시 저장:** 모바일에서 후면 카메라 호출(브라우저·기기 설정에 따라 파일 선택기가 표시될 수도 있음), 원본 사진과 기기 시각을 IndexedDB에 바로 보관
- **사진 불러오기 / 수동 기록 / 샘플 체험:** 실내 카메라 없이도 사용성 확인 가능
- **OCR 자동 인식 시도:** 사진 속 `B3`, `C-27` 같은 영문·숫자 표기를 Tesseract.js(영어 모델)로 읽어 기록에 제안. 인식 결과는 **추정**이며 사용자가 확인 또는 수정. CDN·모델 다운로드가 불가능하면 자동 인식이 실패하지만 사진 저장은 그대로 유지
- **현재 주차 카드:** 주차한 층수, 구역, 번호, 주차 경과 시간, 출입구·엘리베이터 메모
- **내 차 찾기:** 사진/주차 표기/출입구 사진 확대, 위치 정보 공유, 완료 처리
- **주차 이력:** 완료된 기록 확인, 다시 활성화, 삭제
- **설정:** OCR 켜기/끄기, 전체 기록 삭제
- **PWA:** 서비스 워커가 앱 화면 파일을 캐시. 지원 브라우저에서 홈 화면에 설치 가능

## 2. 모바일에서 여는 방법

### GitHub Pages (권장)

1. GitHub의 **새 저장소**를 만든 다음 압축파일 내부의 **파일과 폴더**를 저장소 루트에 업로드합니다. (ZIP 자체만 올리면 안 됩니다.)
2. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다. 업로드된 `.github/workflows/pages.yml`이 배포를 담당합니다. 최초 선택 후 **Actions → Deploy Chayeogi to GitHub Pages → Run workflow**로 한 번 실행하세요.
3. 배포된 HTTPS 주소를 휴대폰 Safari 또는 Chrome으로 접속합니다.
4. 홈 화면에 추가해 카메라·기록 흐름을 테스트합니다.

기존 GitHub Pages 사이트의 하위 폴더에 전체를 업로드해도 됩니다. `manifest.webmanifest`와 서비스 워커의 경로는 상대경로로 작성했습니다.

### 컴퓨터에서 로컬 실행

```bash
cd parking-memory-mvp
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다. 휴대폰에서 LAN IP로 접속하면 보안 정책 때문에 서비스 워커나 일부 기능이 제한될 수 있으므로 HTTPS 배포를 권장합니다.

## 3. 검증 시나리오

1. **샘플로 체험하기** → 현재 주차 화면 → **내 차 찾기** → **차를 찾았어요** → 지난 기록 확인
2. **사진 찍고 바로 기록** → 주차 안내 표지판 촬영 → 사진이 바로 보관되는지 확인 → OCR 추정값 수정 → 출입구 메모 추가
3. **기존 카메라로 촬영한 사진 불러오기** → 동일한 방식으로 보관·복귀 화면 확인
4. 모바일 브라우저 새로 고침 → 사진·주차 정보가 유지되는지 확인
5. 데이터 연결 끊고 다시 접속 → 앱 화면과 기존 기록이 표시되는지 확인 (최초 접속 후 오프라인 캐시가 완료된 경우)

## 4. 기술·보안상 범위

- **백엔드·회원가입 없음.** 세션 및 사진은 현재 기기 브라우저의 IndexedDB에만 저장합니다. 사용자가 브라우저 데이터를 지우거나 브라우저가 사이트 저장소를 정리하면 기록은 사라질 수 있습니다. 다른 기기 간 동기화는 제공하지 않습니다.
- 자동 OCR은 Tesseract.js를 CDN에서 불러와 브라우저 안에서 처리합니다. 이 구현은 OCR 모델도 인터넷에서 가져옵니다. 별도 서버로 촬영 이미지를 전송하는 코드는 없습니다. OCR이 정확하지 않을 수 있으므로 자동 추정값과 직접 확인한 값을 구분합니다.
- 현재 위치 기반 시설명 확정, 실제 주차면 자동 탐지, 실내 내비게이션, 자동 차량 하차 알림, 잠금화면 전용 카메라는 **아직 구현하지 않았습니다.** 별도 네이티브 앱 기능으로 검토해야 합니다.
- iOS에서 홈 화면 설치를 하더라도 기본 카메라 잠금화면 동작을 대체하는 것은 아닙니다.
- 차량 사진에 사람·번호판이 찍힐 수 있으므로 동승자 공유 시 주의해야 합니다.
- 사진은 무손실 원본 Blob으로 보존하므로 여러 건을 기록하면 저장 공간을 많이 사용할 수 있습니다.
- 기기 촬영 기록은 공식적인 입차 시간 증명이 아닙니다.

## 5. 향후 우선순위

- 사진 저장 성공률, 기록 완료 시간, 기존 카메라 대비 자발적 선택률의 사용자 실험
- OCR 인식 결과의 정확도 측정, 한글 간판 인식 확대
- 저장소 사용량 관리·사진 백업/내보내기
- 잠금화면 실행, 차량 하차 감지, 알림 사용성의 네이티브 앱 실험

> 배포하지 않은 HTML 파일을 iPhone 파일 앱에서 직접 열면 브라우저 저장소와 카메라 동작이 제한될 수 있습니다. 실제 테스트에는 HTTPS 주소를 사용하는 것이 좋습니다.
